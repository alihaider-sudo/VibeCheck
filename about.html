About VibeCheck

VibeCheck is an educational publication for university students and beginner web developers. It teaches you to build with AI while still thinking like a developer.

The problem

AI tools can produce a full web page in seconds. For a beginner, that is exciting, and risky. The code often looks right, so it gets accepted without being read.

The result is websites with weak structure, layouts that break on phones, poor accessibility, and a design that looks like everyone else's. Worse, the person who published it cannot explain or fix it.

Our philosophy

VibeCheck is not anti-AI. We use AI tools and we think you should too. We are against using them blindly.

  • Understand every line before you ship it.
  • Review generated code like you would review a classmate's work.
  • Test on small screens, with a keyboard, and in real conditions.
  • Improve in small steps, and learn from each change.

Who it is for

University students and beginner web developers: people who know a little HTML and CSS, are starting to use AI tools, and want to build things they can actually explain.

What you can learn

  • How to spot generic, template-like design and replace it with intentional choices.
  • The HTML and CSS mistakes beginners make most often, and the fixes.
  • A repeatable routine for reviewing AI-generated code.
  • How to make a page work on any screen before you publish it.
